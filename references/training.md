# Programmes de force — cycle A/B/C (type FORGE)

Échauffement 5–10 min + 2 séries de montée en charge. Repos : 2–3 min (polyarticulaires), 60–90 s (accessoires).

| Séance | Exercices (séries × reps) |
|---|---|
| A — Poussée + squat | Squat 4×5–8 · Développé couché 4×6–10 · Développé militaire 3×8–10 · Dips/pompes 3×max · Gainage 3×45 s |
| B — Tirage + charnière | Soulevé de terre roumain 4×6–10 · Rowing barre 4×8–10 · Tractions/tirage vertical 3×6–10 · Face pull 3×15 · Curl 3×10–12 |
| C — Full body / accessoires | Fente bulgare 3×8–10/jambe · Développé incliné haltères 3×8–12 · Rowing unilatéral 3×10 · Hip thrust 3×10–12 · Farmer walk 3×30 m |

## Progression
- Double progression : atteindre le haut de la fourchette sur toutes les séries → +2,5 kg haut du corps, +5 kg bas du corps.
- 2 échecs consécutifs → décharge −10 %, puis remonter.
- Semaine de décharge (−40 % volume) toutes les 6–8 semaines ou si fatigue persistante.

## Substitutions genou (douleur, fragilité, post-blessure)
| Remplacer | Par | Notes |
|---|---|---|
| Squat barre | Box squat (amplitude limitée), goblet squat sur box, leg press amplitude partielle | Genou aligné sur le pied, pas de douleur > 3/10 |
| Fente bulgare | Step-up bas, pont fessier unilatéral | Éviter impacts et pivots |
| Leg extension lourd | Leg extension léger 30–60°, isométrie quadriceps | |
| Sauts | Vélo, rameur | |

## Substitutions dos (lombalgie, fragilité)
| Remplacer | Par | Notes |
|---|---|---|
| Soulevé de terre / RDL barre | Hip thrust, pull-through poulie, RDL haltères légères | Colonne neutre, pas de flexion lombaire chargée |
| Rowing barre penché | Rowing poitrine appuyée, rowing assis poulie | |
| Squat barre dos | Goblet squat, leg press (bassin plaqué), belt squat | |
| Développé militaire debout | Développé assis dossier | |
| Crunchs | Dead bug, bird dog, planche, Pallof press | Base McGill |

Signaux d'arrêt : douleur aiguë ou croissante, gonflement, engourdissement ou douleur irradiante → stop et avis professionnel.

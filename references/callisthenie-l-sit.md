# L-sit (tenir le L)

Source : [Tenir le L](https://youtu.be/5FxjxP50Fc8) — Brieuc Le Dantec.

Porter son poids en appui, bras tendus, pour aller vers les jambes horizontales. Préparer aussi les **poignets** (l’appui les casse vite).

## Progressions

1. **Se soulever**, bras **le plus tendus possible**, tête « sortie » (pas rentrée dans les épaules), pas recroquevillé. Si les bras sont courts par rapport au buste, le sol peut être injuste : passer sur **barres parallèles** ou **entre deux chaises**, corps dans le vide. Ne pas conclure trop vite « je ne décolle pas » : la force d’abaisser les épaules change beaucoup les choses. Si c’est très lourd : élastique sous les fesses, ou une jambe qui aide un peu, en réduisant l’aide honnêtement.
   - Dose si c’est dur : tenues max, ~2 min de pause, 5–6 essais, **3–4 fois/semaine**.
2. **Avancer les hanches** (astuce : genoux vers le visage). Ça place le bassin et déplace le poids vers les triceps. Effort à fond **6–8 s**, pause **~1 min**, 5–6 fois, jusqu’à amener les hanches au niveau des mains, voire devant.
3. **Tendre les jambes** : même logique 6–8 s à fond.

Ne pas brûler les étapes. Une jambe tendue puis l’autre peut servir d’intermédiaire (détail visuel, à doser sans douleur).
